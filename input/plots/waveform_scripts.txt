# PDS waveform characterisation, HD vs VD (SOLAR PDS/waveform/export, bundled by src/tools/export_waveform_repo.py): plots from the pickles in input/data/PDS/waveform/.
# Sync:  ./scripts/sync_solar_data.sh --waveform          Run:  python run_plot_scripts.py -s waveform   (routed to THESIS/figures/reco/waveform/)
# Columns and categories: input/data/PDS/waveform/README.md. Times in us, 16 ns ticks for both detectors; the average waveforms are peak-aligned (t = 0 at the peak).
# Comparison: Source Matched (flash matched to each TPC cluster), Signal Signal (MARLEY light), HD Central marley_waveform vs VD Top marley_flash, labelled by
# detector (Geometry hd/vd). Samples are picked by their Sample label (Config x Name alone would also keep VD Top marley_waveform).
# Colours and legend names: pds_waveform_color / pds_waveform_label in config/plot_params.json (HD C1, VD C2).

# 1. Simulated single-photoelectron responses (peak-normalised)
scripts/script_iterable_scan.py --path PDS/waveform --datafile spe_responses -i Geometry -x Time -y Normalised --plot_type line --rangex 0 5 --horizontal 0 --horizontal_style : --labelx 'Time ($\mu$s)' --labely 'Normalised Amplitude' --title 'Simulated Single-Photoelectron Response' --labelz Detector --iterable_mapping pds_waveform_label --iterable_color_mapping pds_waveform_color

# 2. Example raw waveforms, 100-1000 PE (baseline-subtracted, peak-aligned; --y_row picks one of the up to 8 stored per row). Chosen by eye from the
#    2026-09-28 export: HD row 1 (row 0 is almost all NaN), VD row 0 (rows 1-7 start mid-pulse: the stored 0.64 us before the peak is shorter than the
#    VD build-up; rows 1 and 2 are identical). Recheck the rows after a re-export.
scripts/script_iterable_scan.py --path PDS/waveform --datafile waveform_examples -i Geometry -x Time -y Waveforms --y_row 1 --select Source Signal PEBin Geometry Sample -s Matched Signal 100-1000 hd 'HD central APA (LAr), marley, PIC 2026-09-28' --filename_select Geometry --plot_type line --rangex -0.64 8 --horizontal 0 --horizontal_style : --labelx 'Time from Peak ($\mu$s)' --labely 'Amplitude above Baseline (ADC)' --title 'HD Raw PDS Waveform - 100-1000 PE' --labelz Detector --iterable_mapping pds_waveform_label --iterable_color_mapping pds_waveform_color
scripts/script_iterable_scan.py --path PDS/waveform --datafile waveform_examples -i Geometry -x Time -y Waveforms --y_row 0 --select Source Signal PEBin Geometry Sample -s Matched Signal 100-1000 vd 'VD nominal (10 ppm Xe), marley, FNAL 9,967 jobs' --filename_select Geometry --plot_type line --rangex -0.64 8 --horizontal 0 --horizontal_style : --labelx 'Time from Peak ($\mu$s)' --labely 'Amplitude above Baseline (ADC)' --title 'VD Raw PDS Waveform - 100-1000 PE' --labelz Detector --iterable_mapping pds_waveform_label --iterable_color_mapping pds_waveform_color

# 3. Per-waveform charge-containment distributions (unit-area density), all PE; ADC per PE as a supplementary plot.
#    Only T50/T90/T99 are histogrammed over the full range (0-4.8 us): the exported PeakTime (0-0.50 us), RiseTime (0-0.33 us) and FWHM (0-2.0 us)
#    histograms cut the VD distributions (64 %, 38 %, 92 % of the waveforms inside) and are normalised to the in-range entries, so those three
#    parameters are shown as unbinned medians and quantiles vs PE bin (block 4) until the SOLAR export widens their ranges.
scripts/script_iterable_scan.py --path PDS/waveform --datafile waveform_features -i Geometry -x Values -y Density --variables T50 T90 T99 --select Source Signal PEBin Sample Sample -s Matched Signal All 'HD central APA (LAr), marley, PIC 2026-09-28' 'VD nominal (10 ppm Xe), marley, FNAL 9,967 jobs' --plot_type step --rangex 0 4.8 --labelx 'Time from Onset ($\mu$s)' --labely 'Density' --legend_loc 'upper center' --rangey 0 4.6 --compact --title 'PDS Waveform Charge Containment' --variable_label_map '{"T50":"$T_{50}$","T90":"$T_{90}$","T99":"$T_{99}$"}' --labelz Detector --iterable_mapping pds_waveform_label --iterable_color_mapping pds_waveform_color
scripts/script_iterable_scan.py --path PDS/waveform --datafile waveform_features -i Geometry -x Values -y Density --variables ADCperPE --select Source Signal PEBin Sample Sample -s Matched Signal All 'HD central APA (LAr), marley, PIC 2026-09-28' 'VD nominal (10 ppm Xe), marley, FNAL 9,967 jobs' --plot_type step --rangex 0 10 --labelx 'Peak Amplitude per PE (ADC/PE)' --labely 'Density' --title 'PDS Waveform Peak Amplitude per PE' --labelz Detector --iterable_mapping pds_waveform_label --iterable_color_mapping pds_waveform_color --legend_loc 'upper right'
